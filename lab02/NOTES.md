## Git и GitHub — в чём разница

- Git — распределённая система контроля версий, работает локально на моём компьютере. Хранит историю, ветки, индекс, умеет всё без интернета.
- GitHub — облачный хостинг для Git-репозиториев. Хранит копию репозитория и добавляет pull request'ы, issues, Actions, веб-интерфейс.

Git работает и без GitHub. GitHub без Git смысла не имеет.

### Что сравнивают git diff и git diff --staged

- git diff (до git add) показывает разницу между рабочей папкой и индексом — что я изменил, но ещё не подготовил к коммиту.
- git diff --staged (после git add) показывает разницу между индексом и последним коммитом — что именно уйдёт в следующий коммит.# Git и GitHub — практика

## Рабочая папка, индекс и коммит

- Рабочая папка (working directory) — набор файлов на диске, которые я вижу и редактирую. Здесь появляются новые файлы и правки, ещё не известные Git.
- Индекс (staging area) — промежуточная область, куда командой git add я складываю изменения для следующего коммита. Индекс позволяет собрать коммит по частям.
- Коммит (commit) — зафиксированный снимок состояния индекса с уникальным хешем, автором, датой и сообщением. Коммит — атомарная единица истории.
- ## Ветки (дополнение)

- Ветка — подвижный указатель на коммит. Даёт независимую линию разработки.
- При новом коммите указатель ветки автоматически сдвигается на новый коммит.
- Слияние (merge) переносит изменения из одной ветки в другую и при необходимости создаёт коммит слияния с двумя родителями.
